# The review follow-up: baseline against the new build

Generated by `backend/tests/eval/build_followup_comparison.py` from the committed records; it calls no provider. Metric versions: required_phrase_coverage = phrase-v1, evidence_recall = evidence-v1. Dataset `quality-v1`, evidence gold `evidence-gold-v1`.

Baseline = the build that was reviewed (`0fe9a95`); new build = the commit named in each run's manifest. Code, configuration, prompt versions (answer-v1/edit-v1 against answer-v2/edit-v2), schema hashes and dataset fingerprints are in the manifests; one run of each. With so few items, differences of a single item are noise, and these are measurements of one model on one synthetic corpus.
